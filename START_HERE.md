## 🚀 The 3-Step Quick Start

```bash
# Step 1: Get API Key (2 min)
# Visit: https://aistudio.google.com/app/apikey
# Click "Create API Key"
# Copy the key

# Step 2: Set Environment Variable (1 min)
set GOOGLE_API_KEY=paste_your_key_here

# Step 3: Run App (1 min)
pip install -r requirements.txt
streamlit run app.py
```

Done! 🎉 Open http://localhost:8501

## 🆘 Common Questions

### Q: Do I need a Google account?
**A:** Yes, to get the API key. It's free.

### Q: Does the AI work offline?
**A:** No, chatbot needs internet. ML models work offline after initialization.

### Q: Can I use without API key?
**A:** Most features yes, but chatbot won't work.

### Q: Is my data secure?
**A:** Yes, all keys use environment variables, never hardcoded.

### Q: Can I deploy to cloud?
**A:** Yes! Streamlit Cloud, Heroku, AWS - all supported.

## 🚨 Stuck on Setup?

### 99% of issues are:
1. **API key not set** → Check AI_SETUP_GUIDE.md section "Set Environment Variable"
2. **Dependencies missing** → Run `pip install -r requirements.txt`
3. **Wrong Python version** → Use Python 3.8+
4. **Port already in use** → Run `streamlit run app.py --server.port 8502`

### 100% of issues solved in:
👉 [`AI_SETUP_GUIDE.md`](AI_SETUP_GUIDE.md) → Troubleshooting section
